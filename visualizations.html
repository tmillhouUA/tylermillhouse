Graph Search Algorithm Visualizer

An interactive visualization of classical graph search algorithms. Generates random weighted graphs and animates how different algorithms explore them, with controls for playback speed, step-by-step execution, and node-shading overlays that illustrate heuristic, cost, and evaluation function values.

Map Coloring with Backtracking

An interactive visualization of backtracking search applied to the US map coloring problem. Animates depth-first search with configurable variable ordering (MRV, degree) and inference methods (forward checking, MAC), while tracking assignments, backtracks, and constraint violations in real time.

Graph Search Sandbox

An interactive sandbox for exploring classical graph search algorithms on a customizable grid. Prune nodes to create mazes and obstacles, then animate BFS, UCS, DFS, Greedy, and A* step by step. Supports repositioning start and goal nodes and stepping through the search manually.
