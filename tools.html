Trip Plotter

A browser-based tool for creating custom travel maps for pen plotting or conventional printing. Build and style multi-trip itineraries on an interactive Mercator map, then save plotter-friendly SVG files. Suitable for flights, road trips, or any combination thereof.

Conway Dithering

A web tool that converts images into one-bit Conway's Game of Life patterns using an evolutionary algorithm. The output is a genuine GoL state — not a stylistic imitation — produced by optimizing precursor configurations tile by tile. Use to create the cover of Dennett's Real Patterns in Science and Nature (MIT Press, 2026).

Checkers Evaluation Explorer

A teaching tool for designing and testing heuristic evaluation functions for depth-limited minimax search, using checkers as the domain. Define two weighted-feature evaluation functions, then run them head-to-head or play against your creation.
