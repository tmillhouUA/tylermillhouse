Trip Plotter

A browser-based tool for creating custom travel maps for pen plotting or conventional printing. Build and style multi-trip itineraries on an interactive Mercator map, then save plotter-friendly SVG files. Suitable for flights, road trips, or any combination thereof.

Conway Dithering

A web tool that converts grayscale images into one-bit Conway's Game of Life patterns using an evolutionary algorithm. The output is a genuine Game of Life state — not a stylistic imitation — produced by optimizing precursor configurations tile by tile. Originally developed to create the cover of Dennett's Real Patterns in Science and Nature (MIT Press, 2026).
